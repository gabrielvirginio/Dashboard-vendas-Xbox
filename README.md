# 🎮 Dashboard de Vendas Xbox — Análise de Dados com Excel

## 📊 Sobre o Projeto

Este projeto consiste no desenvolvimento de um **Dashboard de Vendas do Xbox utilizando Excel**, com foco na análise quantitativa dos registros de vendas, identificação de padrões de consumo e geração de insights para apoiar a tomada de decisão.

A solução permite explorar os dados de forma dinâmica por meio de filtros interativos, indicadores-chave de desempenho (KPIs) e gráficos analíticos, facilitando a compreensão da distribuição das vendas por modelo, período, jogo e modalidade de plano.

O dashboard foi estruturado para transformar os registros da planilha em informações visuais e objetivas, proporcionando uma visão consolidada do comportamento das vendas conforme os critérios selecionados.

## 🎯 Objetivos

- Analisar a distribuição dos registros de vendas por modelo e modalidade de plano.
- Identificar os modelos com maior volume de registros.
- Avaliar a participação dos planos renováveis e não renováveis.
- Comparar a distribuição entre planos que incluem jogos e planos exclusivamente de plataforma.
- Identificar períodos do ano com maior concentração de registros.
- Facilitar a exploração dos dados por meio de filtros interativos.

## 🔎 Filtros Interativos

O dashboard disponibiliza filtros para segmentar a análise conforme as características dos registros:

- **Tipo de renovação:** planos renováveis ou não renováveis.
- **Modalidade do plano:** planos que incluem jogos ou somente plataforma.
- **Período da venda:** seleção do período para análise temporal.

A combinação desses filtros permite visualizar diferentes recortes dos dados e comparar padrões de distribuição entre os segmentos selecionados.

## 📈 Indicadores e Visualizações

### KPIs — Indicadores-chave de desempenho

- **Total de registros:** quantidade de registros de vendas considerados na análise.
- **Variedade de modelos:** quantidade de modelos distintos identificados na base de dados.

### Gráficos analíticos

- **Distribuição temporal:** apresenta o volume de registros por período do ano.
- **Volume por jogo:** demonstra a distribuição dos registros entre os jogos disponíveis na base.
- **Distribuição por tipo de plano:** permite comparar as modalidades de plano identificadas nos dados.

As visualizações são atualizadas conforme os filtros aplicados, permitindo uma análise segmentada dos registros.

## 💡 Insights e Análises

A exploração do dashboard permite investigar questões relevantes para a compreensão do comportamento das vendas:

- **Modelos mais vendidos:** identificação dos modelos com maior número de registros na planilha.
- **Preferências por plano:** comparação da distribuição entre modalidades renováveis, não renováveis, planos com jogos e planos exclusivamente de plataforma.
- **Sazonalidade:** identificação de períodos do ano com maior ou menor concentração de registros.
- **Análise segmentada:** avaliação de como a distribuição dos registros varia conforme o período e as características dos planos selecionados.

Os insights devem ser interpretados com base nos resultados efetivamente apresentados pelo dashboard, sem pressupor tendências ou preferências que não estejam sustentadas pelos dados.

## 🧹 Qualidade e Tratamento dos Dados

A análise utiliza os registros disponíveis na planilha como fonte de informação.

Para garantir uma interpretação consistente dos indicadores, é importante considerar os seguintes critérios:

- As contagens são baseadas nos registros existentes na base de dados.
- A variedade de modelos corresponde à quantidade de modelos distintos identificados.
- Os resultados dependem da integridade e do preenchimento dos campos utilizados nos filtros e gráficos.
- Registros duplicados, campos vazios ou inconsistências podem influenciar os resultados caso não sejam tratados previamente.
- O total de registros não deve ser interpretado automaticamente como quantidade de unidades vendidas, receita ou número de clientes únicos.

**Nota metodológica:** os indicadores representam contagens dos registros da planilha e não constituem, por si só, uma medida de faturamento ou rentabilidade.

## ⚙️ Tecnologias e Recursos

- **Microsoft Excel:** organização dos dados, construção dos indicadores, aplicação de fórmulas e elaboração das visualizações.
- **Filtros interativos:** segmentação dos dados por modalidade de plano e período.
- **Gráficos e KPIs:** representação visual dos principais indicadores da base.
- **Análise exploratória de dados (EDA):** investigação de distribuições, concentrações e padrões observáveis.

## 🖥️ Funcionamento do Dashboard

Os filtros e gráficos funcionam localmente no Excel, sem depender de serviços externos de visualização de dados.

Para utilizar o dashboard:

1. Baixe o arquivo Excel disponibilizado no repositório.
2. Abra o arquivo em uma versão compatível do Microsoft Excel.
3. Utilize os filtros disponíveis para selecionar os critérios desejados.
4. Analise os KPIs e gráficos atualizados conforme a segmentação aplicada.

A atualização automática dos indicadores depende da configuração das fórmulas, tabelas, gráficos e recursos interativos implementados no arquivo.

## 📌 Considerações Finais

O Dashboard de Vendas Xbox demonstra a aplicação de recursos do Excel para análise e visualização de dados, reunindo indicadores quantitativos e filtros interativos em uma interface voltada à exploração de informações comerciais.

O projeto reforça a importância da organização dos dados, da definição adequada dos indicadores e da apresentação visual para identificar padrões, comparar segmentos e apoiar análises orientadas por evidências.

**Foco do projeto:** análise exploratória de dados, visualização de indicadores e geração de insights a partir de registros de vendas.
